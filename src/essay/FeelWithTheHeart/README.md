“The best and most beautiful things in the world cannot be seen or even touched — they must be felt with the heart” — Helen Keller

這兩天休息了一下，前些日子寫引擎寫到有點累了，老實說明明是很喜歡的東西，有了時間壓力之後卻又沒那麼開心了。 看到中肯小兔分享了一部漫畫，就去看了一下，叫做「塗鴉日記」，想著在休息的同時順便找找自己的狀態，結果看一看感觸好深

主角住在鄉下，由於是鄉下所以大家普遍都會對他的畫給與讚賞，而她因為想畫漫畫，所以在同學的介紹下去了當地一位畫家開的補習班上課，因為之前有看過「藍色時期」，因此我大概可以猜的到後面會有什麼發展，總之日本的藝大應該是非常難考，她在那補習班努力了很久，結果後來卻連連落榜，後來運氣很好的最後一間成功上了，中間的過程與心境雖然帶得比較粗，沒有像藍色時期那樣詳細的描繪，但我覺得塗鴉日記這部分還是描寫的相當不錯的，很推薦看一下

但上了大學後她卻提不起筆了，渾渾噩噩的過了四年就突然要面臨出社會的問題，中間雖然老師有來探訪她，帶了酒準備聊聊天，卻因為她當時的生活習慣導致錯失了這次機會。 畢業後暫且回了老家，老爸給她介紹了個公司，她進去後馬上確信自己不適合，看著眼前的螢幕開始在思考人生，發現自己努力了這麼久，考上了美術大學，卻始終都沒有開始畫漫畫，結果痛苦拉扯了一陣子後，她終於拿起了筆開始了畫漫畫

這幾天我 code 也越寫越迷茫，這學期我幾乎沒什麼去學校，感覺我好像只有報告或期中會出現在學校那邊，但就算是這樣，還是一直被作業追著跑，老實說自己都不知道在忙什麼，但就是一直有事，做到像是喉嚨裡面有什麼被卡住一樣。 之前在數學系的時候也是這樣，我以為到了這裡會有改變，雖然的確這裡的東西我比較熟悉，做的也比較快，但我發現本質上來說我似乎並無法適應這種在多個工作間互相切換的狀態

這種無法專心在一件事上的工作型態不曉得工作後是不是也是常態，但總之這讓我很難以進入狀態。 在中央的時候我常常就索性不管其他事，專心開始寫自己的專案了，結果就是畢不了業，轉學到了師大重回大二。 漫畫裡也有類似的場景，雖然原因不同，但拿著不是自己工作得來的錢生活，卻感覺自己的步調很亂，生活不在軌道上的心情讓我感觸很深。 所幸在數學系的四年讓我練到了一些工作管理的能力，雖然整個人都很不在狀態內，但至少仍能完成這學期的作業與考試

擁有明確的目標是很重要的一件事，就算理性上能知道自己正在往前，但感性上卻很難接受這件事，進而感到迷茫，因此才需要有個明確的目標與規劃，同時養成記錄自己努力的習慣也是件很重要的事，這些都能夠很大程度上的照顧到自己的情緒

這幾個月就是因為，在這樣忙碌的情況下漸漸忘記了想要去當時任天堂工作的強烈心情，漸漸的心理就感受不到踏實的感受了，而又由於 vibe coding 的存在，情感上踩空的感覺越來越多，最後實在受不了就休息了兩天，而且是在工期剩四天的情況下休了兩天

也許自己該有意識的提醒自己的目標，擁有目標的話便會自然而然的用心體會自己所做的每一件事，而將踏實感銘刻於心中
