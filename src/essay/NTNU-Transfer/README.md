## 與老師討論後的 Feedback

### 國師 Feedback

建議：

1. 全力衝資工系 or 衝(資工+電機)。 若要申請電機，需要有一套CS、一套EE申請資料。(電機可能申請上也會念得很辛苦，因為有三電一工，有很多數學)
2. 準備 resume(履歷)、自傳(含轉系動機)、讀書計畫、有利資料。
3. 建議寫中文，審查人比較讀得懂(有耐心?!)。
4. 以資工系為主，中大以後、幾間前幾名私校都可考慮。(淡江資工系可再投)。
5. 去問許富皓老師，中央資工有什麼方法轉入嗎(含降轉)?
6. 我會寫一封推薦信，讓你當有利資料。內含這幾年相關的project, courses, MCL等等。(5/12前給你)
7. 修課數學量 數學>>通訊>電機>>資工。
8. 將文件圖形化(好理解有記憶點)，將經歷project化、展現自身優點。隱惡揚善。

### 和聿廣的討論整理

- 簡歷用條列式的寫，修過的課也要寫，成績不好的不要寫上去
- 自傳先寫動機，再來寫學習歷程
- 讀書計畫最好要有指標，ex. 轉學後要唸英文，目標是考到多益 xx 分
- 注意修業年限
- 把高教計畫做過的項目條列式的寫出來，擔任什麼角色做了什麼事也都寫出來
    - 網管的事也是
    - 請老闆在推薦信裡面也特別註明這個

## 臺師大抵學分的過程

當時忘記寫這段了，但因為今年（2026/09/10）又跑了一次抵免流程，想多抵一些通識，所以這邊也順便把它補上

### 相關注意事項

首先是上下學期都會開放抵免申請，具體日期可以看師大的行事曆，以 [115 年的行事曆](https://www.aa.ntnu.edu.tw/uploads/asset/data/69dcae1f843f75167cb23486/115%E5%AD%B8%E5%B9%B4%E5%BA%A6%E8%A1%8C%E4%BA%8B%E6%9B%86_%E7%B0%A1%E6%98%93%E7%89%88_.pdf?utm_source=chatgpt.com)來說，日期為：

- 115-1：2026/8/24～9/11
- 115-2：2027/2/1～2/26

另外，各系所自己可能還會再進一步限縮開放的時間，例如今年資工系就沒開到 9/11，只開放到 9/4

再來抵免是有上限的，最多只能抵 50 學分，這點要注意一下。 如果選課期間你抵免的申請過了，記得把對應的課退選掉

最後是有些課不是課綱類似就能抵的，例如你不能拿原校的必修來去抵臺師大的通識

### 填申請單

::: tip  
我不知道為什麼我直接開臺師大的系統網頁都會進不去，後來發現用無痕可以進，有類似情況的人可以試試看  
:::

首先先填申請單，整個流程為：

1. 進「[資訊入口網站](https://iportal2.ntnu.edu.tw/myPortal.do?1789045749169)」，點右上角的應用程式來進到選單

   ![](./image/ntnu-portal-applications-menu.png) 

2. 進「日間教務資訊系統」，按「一般科目抵免申請」，然後按「新增一般科目抵免」

   ![](./image/ntnu-credit-transfer-application.png) 

3. 把你原校的課和要抵的課填上去，底下我用我的日文來舉例

   ![](./image/ntnu-credit-transfer-japanese-example.png)

4. 送出申請資料，按鈕在剛剛「新增一般科目抵免」按鈕的右邊

你可以在「抵免申請紀錄查詢」這邊看到申請單的內容和狀態：

![](./image/ntnu-credit-transfer-application-status.png)

### 送申請單

首先是要準備的東西：

- 抵免申請單
  - 最好是以部門為單位來送申請單，例如通識申請一張，資工申請一張，體育申請一張之類的。 因為到時候跑需要把印出來的申請單交給各部門，阿審核要時間，所以你會希望一天就把各個對應的申請單交給各部門，不然會來不及，因此分開印比較好
  - 我當初全部都合起來送一份申請單，然後要跑三個部門，結果三個部門就都要能各交一疊超厚的申請單，而且很雜亂
- 原校成績單
  - 一份申請單要有對應的一張成績單。 所以你有幾份申請單，就印幾份成績單
- 原校對應的課綱
  - 要給課綱（印出來），沒課綱的話抵免可能不會過
    - 我中央資工的資結沒寫課綱，找不到地方印，結果我資結的抵免就沒過

然後就跑大地遊戲：

1. 把申請單送去對應的單位。 例如通識課就送去通識教育中心，資工系的課就送資工系系辦
   - 這部分要注意一下，每個系所可能會有額外的規定，像是這次想去東亞系抵日文課，他們就要求要先跟我要抵的那門日文課的授課老師約時間，請他先簽名，系辦才能受理
2. 等對方通知，通常是會打你電話，然後回去拿他們蓋好章的申請單
3. 將蓋好章的申請單送去你們系的系辦，蓋「所屬系所主管」的核章
4. 把章都蓋好的申請單送到教務組
   - 資工系的話就不用這步，資工系蓋完會直接幫我們送教務處，但是也因為這樣所以要看申請結果你只能上系統看

至此結束，公館跟本部來回跑真的很累，記得善用會到「羅斯福金門街口」的公車：

- [分部人往本部的另一種方法](https://www.dcard.tw/f/ntnu/p/241508630)

## 2026 了，寫一下後記

今天是 2026/09/10，由於最近 MCL 讀書會要來分享一下經歷，所以回來更新一下這篇。 今年弄出了很多成果，真的很感謝 jserv 老師

整體來說我對臺師大還蠻滿意的，必修學分很少，大部分都是選修，雖然不同領域都有卡你一個三學分，但跟中央比起來我覺得彈性很多了（尊貴的中央大學還要你去聽一堆演講才能畢業，還有 CPR==）

課程的部分我覺得我沒什麼資格做評價，因為本人自從轉學後就開始跟著 jserv 老師做研究了，所以基本上學校的課也都是要去不去的，挑一些涼課修而已，有時候發現會過連期中考都沒去XD

但是臺師大資工的 Discord 群組非常活躍，同時臺師大資工我覺得也有很多很猛的 Open Source 玩家，所以無論是修課還是技術，我覺得比起來問我，不如直接去 Discord 問他們就好XD

不過負責辦抵免的系辦姐好兇，還有臺師大的選課系統好爛，有點想念中央的選課系統與和善的系辦姐
